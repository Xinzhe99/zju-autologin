# 通知渠道配置指南

设置 → 掉线通知，选择渠道后按下文获取对应的 Key / Webhook 填入，点「**发送测试**」验证。

**推送时机**：登录连续失败 ≥N 次（默认 3，可设）→ 推送；设备数超限 → 立即推送；网络恢复 → 推送（可关）；月度流量超上限 → 推送。

> **钉钉 / 飞书用户注意**：本工具所有推送的标题都包含关键词「**校园网**」。若机器人启用了关键词安全设置，把关键词设为「校园网」即可正常接收。

| 渠道 | 消息送达 | 获取难度 | 适合人群 |
| --- | --- | --- | --- |
| Bark | iPhone 通知 | ⭐ 最简单 | 用 iPhone |
| Server酱 | 微信服务号 | ⭐⭐ | 用微信、不想装 App |
| 企业微信机器人 | 企业微信群 | ⭐⭐ | 注册过企业微信 |
| 钉钉机器人 | 钉钉群 | ⭐⭐ | 用钉钉 |
| 飞书机器人 | 飞书群 | ⭐⭐ | 用飞书 |
| 邮件 (SMTP) | 邮箱 | ⭐⭐⭐ | 都不想用上面的 |

---

## 1. Bark（iPhone，最推荐）

1. iPhone 在 App Store 搜索并安装 **Bark - 自定义推送**
2. 打开 Bark，首页会显示一条示例 URL：
   `https://api.day.app/AbCdEfGh123456/这里改成你自己的推送内容`
3. 其中 `AbCdEfGh123456` 就是你的 **Key**，复制它
4. 本工具：通知方式选 **Bark**，Key/Webhook 粘贴这段 Key → 发送测试
5. iPhone 收到通知即成功（首次请允许 Bark 发送通知）

- 也可以填自建 Bark 服务的完整地址（以 `http://` 或 `https://` 开头会被识别为完整地址）
- 想要更及时的推送，可在 Bark App 内为该推送开启"重要提醒"（穿透勿扰）

## 2. Server酱（推送到微信）

1. 浏览器打开 **sct.ftqq.com**（Server酱·Turbo 版），用 GitHub 或微信登录
2. 首页复制你的 **SendKey**（形如 `SCT123456XXXXXXXXXXXXXXXX`）
3. 微信扫码关注页面提示的「方糖」服务号（不关注收不到消息）
4. 本工具：通知方式选 **Server酱**，粘贴 SendKey → 发送测试
5. 微信「方糖」服务号会弹出消息

- 免费版每天有 5 条的额度限制，超出当天就收不到了
- 我们调用的是 Server酱·Turbo 接口；Server酱³（sc3.ft07.com）是另一套接口，暂不适用

## 3. 企业微信机器人（推送到企业微信群）

1. 打开企业微信，进入任意一个群（可以建一个只有自己的群）
2. 群设置 → **群机器人** → 添加 → 新建一个机器人（名字随意）
3. 复制 Webhook 地址：
   `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=693aXXXX-XXXX-XXXX-XXXX-XXXXXXXX`
4. 本工具：通知方式选 **企业微信机器人**，把**整段 URL** 粘贴到 Key/Webhook → 发送测试
5. 群里收到机器人消息即成功

- 没有企业微信？个人可以免费注册一个企业微信（不用认证），自己建群即可使用

## 4. 钉钉机器人（推送到钉钉群）

1. 打开钉钉群 → 群设置 → **机器人** → 添加机器人 → 选**自定义（通过 Webhook 接入自定义服务）**
2. 安全设置**必须选「自定义关键词」**，关键词填：
   ```
   校园网
   ```
   （本工具所有推送标题都包含这个词，其它两种安全方式——加签 / IP 段——本工具暂不支持）
3. 完成后复制 Webhook 地址：
   `https://oapi.dingtalk.com/robot/send?access_token=XXXX`
4. 本工具：通知方式选 **钉钉机器人**，粘贴整段 URL → 发送测试
5. 群里收到消息即成功

- **收不到的最常见原因**：关键词没填或填错；或机器人用了"加签"安全方式

## 5. 飞书机器人（推送到飞书群）

1. 打开飞书群 → 设置 → **群机器人** → 添加**自定义机器人**
2. 安全设置选**自定义关键词**，关键词填：
   ```
   校园网
   ```
   （同钉钉，加签 / IP 白名单方式暂不支持）
3. 复制 Webhook 地址：
   `https://open.feishu.cn/open-apis/bot/v2/hook/XXXX-XXXX`
4. 本工具：通知方式选 **飞书机器人**，粘贴整段 URL → 发送测试
5. 群里收到消息即成功

## 6. 邮件 (SMTP)

用自己的邮箱给自己发告警邮件。需要填 5 项：

| 字段 | 说明 | 示例（QQ 邮箱） |
| --- | --- | --- |
| Key / Webhook | 不用填（邮件不用它） | 留空 |
| SMTP 服务器 | 见下表 | `smtp.qq.com` |
| SMTP 端口 | `465`（SSL，推荐）或 `587`（STARTTLS） | `465` |
| SMTP 用户 | 发件邮箱地址 | `123456@qq.com` |
| SMTP 密码 | **授权码**，不是邮箱登录密码！ | 16 位字母 |
| 收件邮箱 | 告警发到哪，一般填自己的邮箱 | `123456@qq.com` |

常见邮箱 SMTP 配置：

| 邮箱 | 服务器 | 端口 | 密码说明 |
| --- | --- | --- | --- |
| QQ 邮箱 | `smtp.qq.com` | 465 | 设置 → 账户 → 开启 SMTP 服务 → 生成**授权码** |
| 163 邮箱 | `smtp.163.com` | 465 | 同样需要开启 SMTP 并生成**授权码** |
| Gmail | `smtp.gmail.com` | 465 | 需开启两步验证后生成**应用专用密码**（且需网络可达 Google） |
| Outlook | `smtp.office365.com` | 587 | 邮箱密码（部分账户需应用密码） |

- SMTP 的推送不走"网络代理"设置以外的特殊通道；若你的网络环境无法直连邮件服务器，请在高级选项配置代理
- 收不到先检查邮箱的**垃圾箱**

## 发送测试失败怎么排查

1. 打开 运行日志 页，最近一条 `通知推送失败：...` 就是原因
2. 常见错误对照：
   - `webhook url required` → Key 没填或不是以 `https://` 开头的完整地址（企业微信/钉钉/飞书必须填完整 URL）
   - 钉钉返回 `310000` → 关键词不匹配或用了加签模式
   - 邮件 `535 authentication failed` → 密码填成了登录密码（应填授权码/应用密码）
   - 超时 → 网络不通；检查是否需要在高选项里配置代理

3. 仍不行：点「复制诊断」把内容发到项目 Issue
